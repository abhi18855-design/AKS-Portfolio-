# Upload your website

This ZIP contains one ready-to-upload docs folder and this guide.

1. Extract the ZIP.
2. Replace the contents of your GitHub repository's docs folder with the contents of this docs folder. Do not create docs/docs.
3. Keep GitHub Pages set to Deploy from a branch → main → /docs.
4. Wait for deployment, then refresh the editor to load the update.

To remove old projects or media from GitHub, also delete their old files from the repository; uploading files does not delete existing ones.

Keep this ZIP as a content and media backup. Import website ZIP in the editor restores it.
